# 案例：Windows 收到消息但没有通知（模拟案例）

> 状态：**DEMO / 虚构案例，非已验证真实故障**  
> 适用版本：DEMO-v0.1  
> 适用平台：Windows  
> 更新日期：2026-10-11  
> 关联规则：[消息通知设置](../product/notifications.md)

## 现象

用户能在会话内看到新消息，但 Windows 桌面没有弹出提醒。

## 演示排查过程

1. 先确认「是否实际收到了消息，只是没有提醒」。
2. 如是，检查客户端的通知开关。
3. 客户端开关已开启，下一步检查 Windows 系统通知权限。
4. 若两项均已开启且问题仍在，记录客户端版本、发生时间与可复现步骤，不能认定故障已经解决。

## 演示结论

模拟案例中，开启被关闭的 Windows 系统通知权限后恢复提醒。

该结果只是历史案例，不能未经验证就推断当前每一位用户的故障原因。
