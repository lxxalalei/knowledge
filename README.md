# 智能客服模拟知识库（仅用于测试）

> **重要：本仓库所有产品步骤、规则、故障案例均为虚构的演示数据，不代表火星 IM 的真实功能，也不得直接导入正式客服知识库。**

本仓库配合 [my_server 智能客服 Agent](https://github.com/lxxalalei/my_server) 验证“用户提问 → 定位文档 → 阅读依据 → 回答 / 继续排查”的流程。

## 检索原则

1. 先通过标题/关键词/症状定位文档，再读取正文，不凭文件名作答。
2. 留意每篇文档的 **适用平台、版本、状态**，不要跨版本或跨平台套用。
3. 产品操作以 `product/` 中明确描述的演示规则为依据，`cases/` 为排查参考。
4. 未覆盖某功能（例如定时发送）不等于“产品不支持”；应回答“在当前资料中无法确认”。
5. 只有读到具体正文才能声称已检索到依据，并在答复中提供文档链接。

## 正式环境映射

本仓库是独立的 **模拟知识源**，不承担公司正式知识管理工作。正式部署时，知识事实应由 KMS（Markdown 文档）与在线表格（结构化状态/案例）提供；可根据效果决定是否通过 OpenViking 索引。不得将本仓库虚构的产品规则迁入 KMS 正式知识库。
